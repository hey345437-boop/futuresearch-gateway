MCP 工具（给会说 MCP 的 AI 用）

        
本网关把 FutureSearch 暴露成三个 MCP 工具：research / forecast / models。任何 MCP 客户端都能挂。

        

        
注意：这三个工具只做「研究」，不能读写你的本地文件。要让它操作本地项目，见 预览 页的说明。

模型前置指令（注入）

        
上游 agent 自带一套输出风格，而它的 API 没有 system 字段 —— 唯一能压过它的地方是任务文本最前面。这里配的会前置拼上去。

        
模型名填 * = 所有模型兜底；填具体模型 = 只覆盖它；存空串 = 该模型不注入。

        

          
          
        

        
        

        

      

    


    
    

      
预览

怎么用

        
把 agent 生成的页面写进上面那个目录，浏览器直接打开对应 URL 就能看。例如 index.html → /preview/index.html。

        
⚠️ 关于「让 AI 读写本地项目」

        

          FutureSearch 的 agent 不支持工具调用（上游 API 没有工具回调面），所以它没法读写你的本地文件 ——
          本网关的 MCP 只提供 research / forecast / models 三个研究类工具。


          要让 AI 真的能操作本地项目，需要的是另一个 MCP（本地 runner：read_file / write_file / run_command），
          由会说 MCP 的 agent 去调它。两者是并列关系：

          research(...) ← 本网关（云端研究）　·　write_file(...) ← 本地 runner（本地手脚）


          dsh / Claude Code 这类客户端自带本地文件工具，所以「生成 HTML 直接预览」这条路是：
          agent 用自带工具写文件 → 写进本网关的预览目录 → 打开 URL。
